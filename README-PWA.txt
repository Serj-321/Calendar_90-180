КАЛЕНДАРЬ 90/180 — ФАЙЛЫ PWA

Содержимое папки:
- index.html       основной календарь с подключением PWA
- manifest.json   название, параметры установки и иконки
- service-worker.js офлайн-кэш приложения
- favicon.ico     исходная иконка ICO
- icons/          иконки PNG 192x192 и 512x512

Для GitHub Pages:
1. Загрузить содержимое этой папки в корень репозитория Calendar_90-180.
2. В настройках репозитория открыть Settings -> Pages.
3. Выбрать Deploy from a branch, ветку main и папку /(root).
4. Сохранить настройки и дождаться публикации сайта.

Ожидаемый адрес:
https://serj-321.github.io/Calendar_90-180/

Важно:
- Данные поездок и настройки хранятся в localStorage браузера, а не на GitHub.
- Старые данные из локального HTML нужно перенести через встроенную резервную копию JSON.
- Офлайн-режим заработает после первого успешного открытия сайта с интернетом.
- Исходный файл календаря сохранён по функциям; добавлены только PWA-метаданные
  и регистрация service worker.
- Иконки PNG увеличены из предоставленного исходника 64x64.
